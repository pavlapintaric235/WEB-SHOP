## Recording preflight

1. Use the existing workspace and AWS resources. The local demo command is in its [README](../experiments/opencv5_guided_scan/README.md). If the short-lived CLI session expired, run `aws login --profile "Web&Shop" --region eu-north-1` before recording. Confirm the selected Region in AWS Settings > View all projects > Overview > Additional Info > Region if needed.
2. Use only the already approved test photos and in-memory controls. The S3 lifecycle schedules uploaded objects for deletion; a repeated live demo may upload a fresh object after expiry. Stay within the 200-current-input guard and the separate **$10 maximum new AWS spend**. The user chose to retain the existing pilot through submission.
3. Put visible labels on every segment: **live AWS OpenCV 5**, **local OpenCV 5**, **archived DINO/SigLIP2 replay**, or **planned integration**. Do not display AWS credentials, local demo passwords, private user information, or a raw full dataset in the recording.
4. Record and review the final video for the under-five-minute limit and factual labels. A judge-accessible recording, code archive/repository, and endpoint or scheduled screen-share still need to be provided; this storyboard does not claim they already exist.
