The workflow, on real shop photographs

A shop photographs its shelves. Software proposes what it sees. A person decides before any stock number changes. Every image and number on this page comes from a verified run on the project's own dataset — nothing here is a mock-up.

Read this first. The recognition results below are provisional ranks, not accuracy. The ten SKU identities are unapproved and the scene labels unreviewed, so the run deliberately reports accuracy_metrics: null. No precision, recall or count-error figure may be read from this page.
1

Register the products

The owner registers each sellable product once, with several clear photographs. Nothing can be recognised that was never registered. Each product keeps two reference representations: the plain box crop, and a masked crop with the background removed.

2

Check the photograph — OpenCV 5, deployed on AWS

Before anything is analysed, OpenCV 5 decodes the image and measures resolution, Laplacian focus variance, and dark/bright pixel share. It answers one question: proceed, or retake. The same module runs locally and in an AWS Lambda in eu-north-1.

Why a retake was asked for

These thresholds were chosen with knowledge of the local examples. They are not calibrated capture-quality thresholds, and the figures above measure agreement between the local baseline and AWS, not whether each decision was correct.

3

Find the products, then propose a SKU

NVIDIA Retail DINO proposes one box per physical item; SigLIP2 ranks every registered reference against each box crop. Pick a scene and step through the stages. The three galleries use identical detector proposals and query embeddings, so the comparison is fair.

4

A person decides — and only then does stock move

Every proposal above is pending. In the Streamlit application the employee splits a merged box, adds a missed item, corrects the SKU and the quantity, and approves. Re-approving the same scan cannot double-count it, and two photographs of one arrangement are reconciled into a single total rather than summed.
